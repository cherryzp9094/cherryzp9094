### 👋 About Me

7년차 Android 개발자입니다. 뷰티샵의 예약·고객·매출을 관리하는 B2B SaaS 앱을 중심으로 교육, 헬스케어, 암호화폐 거래소 서비스의 Android 앱을 만들어 왔습니다.

스타트업에서 Android를 혼자 또는 소수로 맡는 경우가 많아, 구조 설계부터 배포와 운영까지 전 과정을 직접 챙기며 일해 왔습니다. 새 기술은 혼자 익히는 데서 끝내지 않고 팀과 함께 옮깁니다.
